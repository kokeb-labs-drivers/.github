# Getting help

| You want to | Go to |
| --- | --- |
| Ask how to use a driver, or discuss an idea | [Discussions](https://github.com/kokeb-labs-drivers/.github/discussions) |
| Report a bug you can reproduce | An issue in the affected driver repository, using the bug form |
| Ask for a new chip driver | The **Driver request** form in any repository |
| Report a vulnerability | Privately, as [SECURITY.md](SECURITY.md) describes |

Before asking, check the driver's documentation (`docs/` in the repository, and its site once the repository is
public), in particular its troubleshooting and limitations pages. Include the driver's tag or commit, your MCU,
RTOS and toolchain, and the smallest code that shows the problem.

Kokeb Labs Drivers is maintained by a small team. Answers in Discussions come on a best-effort basis; there is no
paid support channel yet.
