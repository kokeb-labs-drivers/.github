# Trademarks

The code in Kokeb Labs Drivers repositories is MIT licensed. The licence covers the code, not the **Kokeb Labs**
name or the logos. Those identify our projects, and we keep them distinct so people can tell what came from us.

The drivers themselves carry no brand: their namespaces, CMake targets and macros are named after the chip, so
using or forking one never means using the name.

## Allowed without asking

- Saying what your project uses or works with: "uses driver-pca9685 from Kokeb Labs Drivers".
- Keeping the name in a fork's history, licence and notices.
- Showing the unmodified logo next to a factual reference, such as a list of libraries a project uses.

## Ask first

- Using the name or logo in the name of your product, company, domain, repository or package.
- Selling hardware, kits or services under the name or logo, or in a way that suggests we made or endorse them.
- Changing the logo, or combining it with your own mark.

## Forks

A fork that is distributed as its own project must use its own name and logo. The code stays MIT; only the name and
logo need to change.

Requests: open a discussion at <https://github.com/kokeb-labs-drivers/.github/discussions> or contact an
organization owner.
